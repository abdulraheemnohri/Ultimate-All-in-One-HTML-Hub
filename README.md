# Ultimate All-in-One HTML Hub

A comprehensive, portable personal dashboard and mini-browser OS built with vanilla HTML, CSS, and JavaScript. This project provides a centralized workspace for productivity, creativity, education, and entertainment.

## 🚀 Features

### 🖥️ Core OS Environment
- **Advanced Window Management:** Draggable, resizable, and focusable windows.
- **Multitasking:** Taskbar to track and switch between running apps.
- **Customization:** Light/Dark theme toggle and personalized wallpaper support (Colors, Gradients, or Images).
- **Searchable Sidebar:** Quickly find and launch apps.
- **Keyboard Shortcuts:**
  - `Alt + S`: Focus app search
  - `Alt + T`: Toggle theme
  - `Alt + Q`: Close active window

### 📂 Integrated Mini-Apps (20+)

#### 📈 Productivity
- **To-Do List:** Manage tasks with local persistence.
- **Habit Tracker:** Track daily streaks and progress.
- **Pomodoro Timer:** Work/Break timer with desktop notifications.
- **Notes:** Private journal/notepad.
- **Calendar:** Event scheduler.
- **Finance Tracker:** Manage income, expenses, and budgets.

#### 🎨 Creativity
- **Digital Sketchpad:** Canvas-based drawing tool with color and brush size controls.
- **Meme Maker:** Create memes by uploading images and adding text.
- **Color Palette Gen:** Generate and copy beautiful hex color schemes.
- **Typography Playground:** Experiment with fonts, sizes, and spacing.

#### 🎓 Education
- **Quiz Generator:** Create and take custom quizzes.
- **Flashcards:** Spaced repetition tool for learning.

#### 🎮 Games & Media
- **Games Hub:** Classic games like Snake and Tic-Tac-Toe.
- **Audio Player:** Listen to your favorite tracks.
- **Video Player:** Integrated video playback.

#### 🛠️ Utilities
- **Calculator:** Modern, safe calculator.
- **Unit/Currency Converter:** Length, weight, and temperature conversions.
- **QR Code Generator:** Generate QR codes for text or URLs.
- **Text Tools:** Formatter, word counter, and case transformer.
- **Password Generator:** Secure, customizable password creator.
- **Mini Browser:** Browse the web within a window.

### 💾 Data & Offline
- **Local Persistence:** All app data is saved to `LocalStorage`.
- **Data Management:** Export all hub data to JSON for backup or import it later.
- **PWA Support:** Service worker for offline access.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3 (Glassmorphism, CSS Variables), Vanilla JavaScript (ES6+).
- **Icons:** FontAwesome 6.
- **Storage:** LocalStorage.

## 📦 Installation & Usage
1. Clone the repository.
2. Open `index.html` in any modern web browser.
3. No build step or server required! (Though a local server like `Live Server` is recommended for PWA features).
